# MVP: Интеллектуальные системы управления городским трафиком

Краткое описание
-----------------

Этот репозиторий содержит минимально жизнеспособный прототип (MVP) интеллектуальной системы управления светофорным регулированием. Цели MVP:

- Предоставить простой, понятный симулятор перекрёстка для исследований и экспериментов.
- Реализовать табличный Q-обучающий агент как baseline для контроля светофоров.
- Добавить простой baseline для прогнозирования потоков (скользящее среднее).
- Предоставить скрипты для тренировки, оценки и демонстрации.

Содержание проекта
------------------

- `simulator.py`: упрощённый симулятор одиночного перекрёстка с двумя направлениями (NS / EW). Описывает процесс прибытия транспорта и обслуживание при зелёном.
- `agent.py`: табличный Q-агент (save/load Q-table).
- `forecast.py`: baseline прогнозирования потока (moving average).
- `train_agent.py`: скрипт обучения Q-агента в среде симулятора.
- `evaluate.py`: оценка обученного агента по метрикам.
- `notebook.ipynb`: минимальная демонстрация и инструкции для интерактивной работы.
- `requirements.txt`: зависимости.
- `DESIGN.md`: дизайн-заметки, формализация среды, метрики, протоколы экспериментирования.

Установка
---------

Рекомендуется использовать виртуальное окружение:

```bash
python -m venv .venv
source .venv/Scripts/activate    # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Быстрый запуск обучения
-----------------------

```bash
python train_agent.py --episodes 400 --steps 200 --out qtable.pkl
```

Оценка обученного агента
-------------------------

```bash
python evaluate.py qtable.pkl --episodes 100 --steps 200
```

Ключевые концепции
------------------

- Среда (симулятор): состояние задаётся длинами очередей в двух направлениях `(queue_ns, queue_ew)`. Действие — какой поток даём зелёный: `0=NS`, `1=EW`.
- Награда: в текущем MVP реализована простая отрицательная сумма длин очередей (минимизация суммарной задержки).
- Агент: табличный Q-learning с эпсилон- жадной стратегией. Подходит как baseline и как точка отсчёта для более сложных методов (DQN, PPO).

Метрики качества
---------------

- Средняя суммарная очередь (avg queue length).
- Средняя задержка на автомобиль (proxy via суммарной очереди).
- Throughput: число обслуженных автомобилей за эпизод.
- Стабильность: стандартное отклонение вознаграждения между эпизодами.

Экспериментальный протокол
-------------------------

1. Запустить `train_agent.py` с фиксированным seed и указанным числом эпизодов и шагов.
2. Сохранить Q-table (`--out`).
3. Прогнать `evaluate.py` на нескольких случайных сидах и сравнить средние метрики.
4. Для репликации фиксируйте все гиперпараметры и seed.

Как расширять проект
--------------------

- Улучшить симулятор: многополосные направления, фазы (включая желтый/переходы), взаимозависимые перекрёстки.
- Заменить табличный агент на DQN или on-policy алгоритмы (PPO) для масштабирования на большие состояния.
- Добавить реальные данные потоков (CSV) и модуль импорта/преобработки для обучения прогнозных моделей.
- Добавить визуализацию (matplotlib / plotly) для просмотра траекторий очередей и сигналов.
- Добавить логирование и метрики (TensorBoard / MLflow).

Файлы и их краткое описание
---------------------------

- `simulator.py`: класс `IntersectionSimulator(arrival_rates=(lambda_ns, lambda_ew), max_queue=50)` — методы `reset()`, `step(action) -> (state, reward, done, info)`, `render()`.
- `agent.py`: класс `QLearningAgent(alpha, gamma, epsilon)` — методы `act(state, epsilon=None)`, `update(state, action, reward, next_state)`, `save(path)`, `load(path)`.
- `forecast.py`: `moving_average_forecast(history, window=5)`.
- `train_agent.py`: CLI-скрипт для обучения; экспоненциальное уменьшение эпсилон, сохранение Q-table.
- `evaluate.py`: CLI-скрипт для оценки среднего вознаграждения обученного агента.

Полезные команды разработки
--------------------------

Запуск тестовой сессии (короткая тренировка):

```bash
python train_agent.py --episodes 50 --steps 100 --out qtable_small.pkl
python evaluate.py qtable_small.pkl --episodes 20 --steps 100
```
