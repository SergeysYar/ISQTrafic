# ISQTrafic — демонстрационный MVP управления трафиком

Проект моделирует простой перекрёсток с двумя направлениями движения: `NS` (север/юг) и `EW` (восток/запад). На каждом шаге в очереди прибывают автомобили, а контроллер выбирает, какому направлению дать зелёный сигнал.

В репозитории есть табличный Q-learning, простое правило «обслуживать более длинную очередь» и baseline-прогноз потока методом скользящего среднего. Это исследовательский MVP, а не готовая система управления реальным перекрёстком.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `simulator.py` | Симулятор очередей и обслуживания машин |
| `agent.py` | Табличный Q-learning агент |
| `train_agent.py` | Отдельное обучение агента |
| `evaluate.py` | Оценка сохранённой Q-table |
| `forecast.py` | Прогноз через moving average |
| `demo.py` | Полная консольная демонстрация |
| `run_demo.bat` | Запуск демонстрации в Windows одним двойным щелчком |
| `DESIGN.md` | Описание модели и идей расширения |
| `requirements-demo.txt` | Минимальная зависимость для консольного demo |

## Быстрый запуск в Windows

1. Установите Python 3.10 или новее: <https://www.python.org/downloads/>. При установке включите `Add Python to PATH`.
2. Откройте папку репозитория `ISQTrafic`.
3. Запустите `run_demo.bat` двойным щелчком.

Скрипт автоматически создаёт `.venv`, устанавливает минимальную зависимость для demo (`numpy`), обучает агента, сравнивает его с контроллером длинной очереди и показывает пошаговый прогон.

Первый запуск требует интернета для установки `numpy`. Результаты сохраняются в `artifacts/demo_qtable.pkl` и `artifacts/demo_metrics.csv`.

## Запуск из PowerShell

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe demo.py
```

Для запуска только консольной демонстрации достаточно `run_demo.bat` и файла `requirements-demo.txt`. Полный `requirements.txt` дополнительно содержит Jupyter, Matplotlib и pandas для дальнейших экспериментов.

Ускоренная демонстрация:

```powershell
.\.venv\Scripts\python.exe demo.py --train-episodes 50 --eval-episodes 10 --live-steps 8
```

Покадровый вывод с задержкой:

```powershell
.\.venv\Scripts\python.exe demo.py --delay 0.2
```

## Что показывает демонстрация

В консоли выводятся средняя суммарная награда, средняя длина очереди и число обслуженных автомобилей для двух контроллеров. Оба контроллера получают одинаковые случайные потоки при фиксированном seed. Затем показывается пошаговая работа Q-learning: выбранное направление, прибывшие и обслуженные машины, текущие очереди и прогноз очереди.

Состояние среды — `(queue_ns, queue_ew)`. Действие `0` включает зелёный NS, действие `1` — зелёный EW. Награда равна минусу суммарной длине очередей: чем меньше очереди, тем выше результат.

## Отдельное обучение и оценка

```powershell
.\.venv\Scripts\python.exe train_agent.py --episodes 400 --steps 200 --out qtable.pkl
.\.venv\Scripts\python.exe evaluate.py qtable.pkl --episodes 100 --steps 200
```

## Частые проблемы

Если `python` или `py` не найден, переустановите Python с включённой опцией `Add Python to PATH` и откройте новое окно PowerShell.

Если не устанавливается `numpy`, проверьте интернет и выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для диагностики запускайте `run_demo.bat` из PowerShell:

```powershell
.\run_demo.bat
```

## Ограничения и следующие шаги

Сейчас используются два направления, фиксированная пропускная способность, пуассоновские прибытия и отсутствие жёлтой фазы. Для приближения к реальной задаче можно добавить полосы, фазы светофора, реальные CSV-данные, датчики, пешеходные переходы, ограничения безопасности и визуализацию.
